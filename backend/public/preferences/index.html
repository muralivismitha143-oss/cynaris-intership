Quiet Hours & Working Window Rules

  • Indian Standard Time (IST): All time conversions default to Asia/Kolkata (UTC+5:30).
  • Overnight Intervals: If Quiet Hours are set from 20:00 to 08:30, reminders generated during this window are shifted to the recruiter's next working start time (09:30 IST).
  • Active Channels: At least one notification channel (Email, WhatsApp, In-App, SMS) must remain active.
